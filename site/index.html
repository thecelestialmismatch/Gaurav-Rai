Each of these started with a problem someone in the contact centre could feel every day.

Bendigo Telco · Amazon Connect

WhatsApp, Messenger and Instagram inside Amazon Connect

The problem

Messages from Facebook and Instagram sat in a separate inbox that nobody watched, while agents worked the phones in Amazon Connect.

What I built

I piloted a fix and took it to production. Node.js Lambda functions route each chat in real time, with DynamoDB lookups along the way, and Amazon Connect sends the conversation through its normal queues and routing profiles.

What changed

WhatsApp, Facebook Messenger and Instagram now land in the same agent workspace as voice calls. Agents answer every channel from one screen.

  • Amazon Connect
  • AWS Lambda
  • Node.js
  • DynamoDB

Bendigo Telco · Agent workspace

The customer record on screen when the call arrives

The problem

Agents looked every caller up by hand in HaloPSA while the customer waited on the line.

What I built

A React and TypeScript panel inside the Amazon Connect agent workspace that fetches the HaloPSA record the moment a call arrives.

What changed

Agents stopped searching by hand, and average handle time dropped 25%.

  • HaloPSA

Things I build on my own

HoundShield

Feb 2026 to present · TypeScript, Next.js, Node.js, Docker

A prompt inspection firewall that checks AI prompts for patient data, controlled information, personal data and secrets on the customer's own hardware, before they reach ChatGPT, Copilot or Claude.

I built it solo with Claude Code and Codex. It has 16 detection engines, 35 scanner patterns, a hash chained audit log and 140 test suites, and it exports PDF evidence mapped to the NIST controls behind CMMC Level 2. It supports an assessment and does not replace one.

houndshield.com Source on GitHub

RipoDoc

Feb 2026 to Aug 2026 · TypeScript, Next.js, PostgreSQL, Docker

Evidence delivery for managed service provider reports. The client keeps the PDF they already trust, and each figure in it opens only the approved rows behind it.

Links are tied to one reader, expire and can be revoked. Every view is written to a SHA 256 hash chain that can be checked offline, and a CI audit fails the build if the app would send report data to an outside service. The source is private.

ripodoc.com

VibeFlow

Mar 2026 to May 2026 · TypeScript, Next.js, Supabase, Stripe

A Chrome extension that scans prompts inside the browser before they reach ChatGPT, Claude, Gemini or Copilot. Its 22 patterns catch keys, passwords, card numbers, source code and health data, with no network call during the scan.

It comes with a Next.js dashboard on Supabase with Stripe checkout.
