## ⟡ About

<img width="100%" src="./assets/about-life.svg?v=1" alt="About Gaurav. Amazon Connect, AWS and Terraform, data and reporting, building with AI. Interests are building AI tools, cricket and travel." />

I'm an AI and data analyst and Amazon Connect engineer based in Melbourne. I build **AWS and Amazon Connect** systems for contact centres, and the **SQL and Power BI reporting** that shows whether they work. Before cloud I spent close to five years in contact centres and IT support, first taking the calls and then leading a team of fifteen, so I build for the agent on the other side of the screen.

- ☁️ **Amazon Connect**: WhatsApp, Facebook Messenger and Instagram routed into Connect, piloted and deployed to production. A CRM panel in the CCP that cut average handle time by 25%.
- 🏗️ **AWS and Terraform**: Lambda, DynamoDB, API Gateway, CloudWatch and CloudTrail, with the Connect setup managed in Terraform.
- 📊 **Data and reporting**: SQL, Power BI and MSPBots dashboards for CSAT, AHT and SLA.
- 🤖 **Building with AI**: Claude Code and Codex as coding agents, Claude and OpenRouter APIs inside the products, and MCP to connect agents to tools.

**Open to** → AI analyst, data, reporting and business analyst roles, plus Amazon Connect and cloud roles, in Melbourne. **Available now.**

## ⟡ Featured Projects

<details open>
<summary><b>🟣 HoundShield: local-only AI compliance firewall</b></summary>
<br/>

Checks AI prompts for controlled information, patient data, personal data and secrets **on the customer's own hardware**, before they reach ChatGPT, Copilot or Claude. Cloud tools in this space scan by sending the prompt to the vendor first, which in a regulated business is the leak you were trying to stop.

| Aspect | Detail |
| :--- | :--- |
| **Stack** | TypeScript · Next.js · React · Supabase · Tailwind · Docker · Vitest |
| **Detection** | 16 detection engines and 35 scanner patterns for CUI, PHI, PII, secrets and ITAR content |
| **Evidence** | SHA-256 hash-chained audit log · PDF evidence mapped to NIST SP 800-171, CMMC Level 2, HIPAA and SOC 2 |
| **Quality** | 140 test suites across the proxy, the web app and the infrastructure |
| **Deployment** | Hosted, self-hosted in Docker, or fully air-gapped |
| **Built with** | Claude Code and Codex, built solo |
| **Links** | [houndshield.com](https://houndshield.com) · [repository](https://github.com/thecelestialmismatch/HoundShield) |

> HoundShield supports a compliance assessment. It does not replace one.

</details>

<details>

<br/>

Client reporting for managed service providers, built around the question every client eventually asks: where did that number come from?

| :--- | :--- |
